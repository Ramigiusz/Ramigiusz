## Projects

### [Azure Zero Trust Lab](https://github.com/Ramigiusz/Zero-Trust-Azure-Lab)
This project presents a **Zero Trust architecture** in **Microsoft Azure**, designed for a hypothetical medical web application. The environment was built using Azure PaaS services, demonstrating the implementation of modern cloud security principles, network micro-segmentation, and secure identity management.

### [Security Automation & Integration Project](https://github.com/Ramigiusz/SOC-Automation-Project)
This project demonstrates the automation of infrastructure monitoring and incident workflows using **Wazuh**, **Shuffle (SOAR)**, and **TheHive**. It highlights the ability to integrate different systems via APIs and webhooks to create automated data enrichment and response pipelines.
